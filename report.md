# Sourcey API Docs Delivery

This delivery provides Sourcey-generated API documentation for the `DevilsAutumn/quater` Python framework.

## Deliverables

1. **Sourcey Project:** Initialized `sourcey-docs` containing the configuration.
2. **Docs Migration:** All existing API reference markdown files have been migrated to Sourcey pages.
3. **Public Access:** A Pull Request has been opened against the official upstream repository (`DevilsAutumn/quater`) for integration.
4. **API Coverage:** Over 30 public API methods are covered across modules like application, auth, routing, testing, observability, etc.
5. **Durable Home:** Once merged, the documentation will live on the official Quater repository/domain, fulfilling the requirement for a project-owned durable home, rather than a throwaway host.
6. **Machine Evidence:** `evidence.json` contains detailed observations of the Sourcey build execution and the exact output.

Thank you!
